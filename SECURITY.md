# Security policy

## Supported versions

The latest 1.x release gets security fixes. Any 1.x updates to a newer 1.x with no manual steps, so if you're on an older version, update first and check that the problem is still there.

| Version | Gets fixes |
| --- | --- |
| Latest 1.x release | Yes |
| Older 1.x releases, release candidates, 0.x | No |

## Reporting a vulnerability

Please don't report a security problem in a public issue or pull request. Report it privately on GitHub instead: on the repository's **Security** tab, choose **Report a vulnerability**, or go straight to <https://github.com/xThrasherrr/ReSkateManager/security/advisories/new>.

Include:

- the manager version, shown in the panel's sidebar or by `ReSkateManager --version`
- how you run it: Windows, Linux or Docker, and whether it's behind a reverse proxy
- the steps to reproduce it, and what someone could do with it

The fix ships in a patch release, along with a GitHub security advisory that credits you, unless you'd rather not be named.

Problems in the ReSkate dedicated server itself belong to the [ReSkate project](https://github.com/Dingo-Shenanigans/ReSkate).
